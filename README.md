# cedwyn-tweak

Tweak — the Cedwyn Estate webapp for front-end design and user-experience tweaks. Served at https://bucklerfamily.estate/tweak/ once registered on unclehowell/cedwyn main (see https://github.com/unclehowell/cedwyn/issues/175).

- `public/index.html` — the register page (390 px first).
- `public/tweaks.json` — open front-end/UX defects, each pointing at its GitHub issue (the issue is the record).
- `public/join.json` — contract for agents: how to take and fix one item, and the rules.
- `public/llms.txt` — the same in plain text.
